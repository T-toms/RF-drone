## 4. 每段的计算（逐段读、逐段算，不要一次把 40 段都放进内存）

1. 段内按 NFFT = 4096 **不重叠**分帧 → 1500 帧。Hann 窗（`np.hanning(4096)`，float32）。
   单帧功率谱 `P = |fftshift(fft(x*w))|^2 / sum(w^2)`。
2. 频率折叠：4096 → 1024 bin，相邻 4 个取**平均**（`P.reshape(1500,1024,4).mean(-1)`）。fftshift 后第 i 个点（0–4095）的 f_norm = (i − 2048)/4096；折叠后第 k 个 bin 覆盖 i = 4k…4k+3，中心 f_norm = (4k + 1.5 − 2048)/4096。DC（i = 2048）落在折叠 bin 512。把 `freq_norm_centers`（1024）以及 2.4G、5.8G 各一份 `freq_mhz_centers`（1024）写入 config。
3. cell = 连续 30 帧（30×4096 = 122,880 点）→ 每段 50 个 cell。对每个 cell、每个 bin：
   - `cell_mean` = 30 帧平均，`cell_max` = 30 帧最大，`cell_min` = 30 帧最小；
   - 转 dB：`10*log10(max(v, 1e-20))`，存 **float16**。用原始数字功率，**不要做任何按录制的归一化**（后续要跨录制比较底噪）。
4. 有效性：帧有效 ⇔ 帧的 4096 个点全部落在该段有效区间内；cell 有效 ⇔ 其 30 帧全部有效。无效 cell 的三个量全部写 NaN。缺段、整段不合格的段：50 个 cell 全 NaN。
5. `frame_power_db`：每帧 `10*log10(mean(|x|^2))`，float32，无效帧 NaN → 每录制 60,000 个值（33.3 µs 分辨率，给后面算突发周期用）。
6. 长时谱（4096 点，未折叠）：所有有效帧的平均功率谱 `psd_mean`（float64 累加）和最大保持 `psd_max`。

## 6. 每录制的特征（写入 `recording_summary.csv`、`occupied_bands.json`）

- **可用频带掩膜**（写 config）：`|f_norm| <= 0.45`，并排除 DC 附近折叠 bin 511、512、513。以下所有特征只在掩膜内统计。
- **底噪 floor_db**（标量）= 掩膜内各 bin「有效 cell 的 `cell_mean_db` 第 10 百分位」的中位数。
- 阈值 `THRESH_DB = 10`（写 config）：
  - 活跃 cell-bin：`cell_max_db > floor + 10`；
  - 持续 cell-bin：`cell_mean_db > floor + 10`。
- 每 bin 占用率 `occ_any`（活跃比例）和 `occ_sus`（持续比例），按有效 cell 计。各存进缓存目录：`occ_any.npy`、`occ_sus.npy`（1024 float32）。
- **占用子带**：`occ_any >= 0.05` 的连续 bin 段，间隔 ≤ 2 bin 的合并；每个子带记录 [lo_MHz, hi_MHz]、宽度 MHz、平均 occ_any、平均 occ_sus。
- 每 cell 活跃 bin 数 `a[t]`（掩膜内）。`duty` = 有效 cell 中 `a[t] >= 5` 的比例。
- **突发周期**：
  - 粗：`a[t]` 去均值后的自相关，滞后 2–200 cell（ms），最高峰相关 ≥ 0.3 时记周期 ms，否则空；
  - 细：`frame_power_db` 有效段的自相关（NaN 处用该录制中位数填补后去均值），滞后 3–900 帧，同样规则，记周期（帧数及 ms）。
- **epoch 边界检查**：以 100 cell（100 ms）为块。块特征 = 块内 `a[t]` 中位数、块内有效 cell 掩膜内 `cell_mean_db` 平均值的中位数（dB）、块的 `occ_any` 向量。
  对**同一 epoch 内所有相邻块对**以及**边界块对（cell 900–999 vs 1000–1099）**分别计算：功率差 |Δ dB|、a 中位数差、占用向量余弦距离。
  记录边界对三个量在"epoch 内相邻块对"分布中的百分位；任一 > 95 百分位 → `epoch_boundary_flag = True`。块内有效 cell < 50 的块不参与。结果写 `epoch_boundary.csv`。
  这只是记录（导师已确认可拼接），**不据此改拼接方式**。

`recording_summary.csv` 每录制一行：folder, session, code, model, state, band, bw_label, combination, n_valid_cells, floor_db, duty, n_subbands, subbands_mhz（简写串）, period_coarse_ms, period_fine_ms, epoch_boundary_flag, 三个边界百分位。
