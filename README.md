# RF-drone：基于深度学习的无人机射频信号检测与识别

大学生创新训练计划（SRTP）项目的代码与文档。

## 研究内容

- **第一阶段：判断有无无人机。** 输入为 20 ms 片段的短时傅里叶时频图（256×256）和 IQ 手工特征，采用 ResNet18 双分支融合网络。
- **第二阶段：识别无人机型号**（计划中）。

## 目录

## 说明

- **仓库只包含代码和文档。** 不包含任何射频数据、缓存、模型权重、图片、PPT/Word 文件和论文 PDF。
  - 实验室采集的数据属于课题组，不公开；
  - DroneRFa 数据集请从原作者发布渠道获取。
- **脚本中的数据路径是作者本机的路径**，复现时需要改成自己的路径。
- 主要依赖：Python 3、PyTorch、NumPy、SciPy、h5py、matplotlib。
