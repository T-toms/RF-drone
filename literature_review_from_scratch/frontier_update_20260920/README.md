## 统计口径（避免误读）

- 本目录不是 PRISMA 系统综述。未完整访问 Web of Science、Scopus、Google Scholar，检索入口为本地 Crossref/OpenAlex 元数据快照（2026-08-15）、原始论文/出版商页面、arXiv 与官方数据/代码页。因此这是**结构化前沿审计**。
- 矩阵中数值字段只填本轮实际核到的内容；未核到的字段写 `NR`。`NR` 表示"本轮未核实"，不表示论文没有该信息。
- 关键数值均在其矩阵行或本目录文档中紧邻来源链接与 `evidence_status` 出现。
- 不同论文的 accuracy 不能横向排名：类别数、切分单位、任务定义和是否开放集都不同，理由见 `04_术语与任务边界.md`。
- 所有对既有实验的引用都指向已验收证据（`work/*.json`、`dronerfa_baseline/outputs/cascade3_evaluation_20260919/report.md`），本目录不修改任何实验结果。

## 已知偏差与限制（必须一并阅读）

1. 矩阵中 `sample_unit_or_length` 有 68/77 行为 `NR`、`split_unit` 有 66/77 行为 `NR`、`code_or_data` 有 58/77 行为 `NR`。这不是遗漏，而是因为绝大多数条目本轮只核到 Crossref/OpenAlex 元数据，没有下载全文；填写窗口长度或切分单位会构成猜测。需要这些字段时应先获取全文再补填，并在 `verification_level` 中升级。
2. 部分前沿条目的关键数值（CageDroneRF 的分层准确率、Sensors 2024 的跨环境数值、S3R 的细分指标）来自 Codex 的受控证据说明或出版商摘要页转述，**尚未逐表复核**，在矩阵中以 `verification_level` 显式标注。
3. `X007` 是项目内部方法论条目（无类别盲检测设计），不是外部论文证据，已在行内注明。
4. 旧版 `deep_research_redo/` 全部文件保持原样；本目录若与旧版冲突，以本目录为准，但冲突必须在交接中说明。

## 引用规范

- 优先使用 DOI 直链、arXiv 原始页面、官方数据页或官方代码仓库。
- 二次综述（`evidence_type=review`）只用于发现文献与建立术语，不作为方法或数值证据。
- 正文只做短引或中文转述，不复制论文长段落。
