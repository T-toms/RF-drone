# 下一阶段实验路线图（依赖顺序）

**检索/规划截止：2026-09-20** ｜ 配套文件：`00_前沿文献矩阵与项目差距报告.md`、`01_文献矩阵.csv`

本路线图只覆盖 DroneRFa 被动 RF 识别主线。任务按依赖顺序串行执行，每个阶段必须先通过"通过条件"才能进入下一个；不自动开始任何阶段。

**全局纪律**

- 每个阶段开始前冻结输入哈希，结束后记录产物哈希；不修改已验收的实验代码、权重、结果 CSV 与 F 盘文件。
- 所有划分文件必须包含固定随机种子、组列表与 SHA256。
- 主指标预注册；一个预先指定的主比较做显著性检验，其余只报效应量与区间。
- 重复单位是独立会话/未知类划分，不是相邻窗口。
- 噪声方式实验（AWGN 之外的噪声建模、真实背景/干扰方式对比）保持 **"待用户以后恢复"**，不排入任何立即执行阶段。

## 阶段 1 `META-SPLIT`：元数据、组划分与最终测试集冻结

| 项目 | 内容 |
|---|---|
| 目标 | 建立文件级（可证时到会话/日期/距离/接收机级）元数据表，生成可复现的组划分，并冻结一份未参与任何选型的 final test |
| 前置依赖 | 无 |
| 数据 | 本机 F 盘 24 个 MAT（`F:\DroneRFa数据集\original`）与 heldout 12 文件（`F:\DroneRFa数据集\heldout_20260917`）；不下载新数据 |
| 模型/基线 | 无模型。产出为数据治理工件 |
| 划分 | 输出 `P1_group_file`（同一原始文件的全部窗口只属于一个集合）；能证明时再输出 `P2_cross_session_day`；`P0_random_window` 只作复现对照并显式标注 |
| 主指标 | 工程指标：组键覆盖率、每类源文件数、划分重叠检查（文件级必须为 0）、划分文件 SHA256 稳定性 |
| 计算成本 | 低（分钟级到小时级，以读取 MAT 头/文件名与索引为主，不做全量扫描） |
| 产物 | `file_metadata.csv`（含 `class/file/session/date/distance/receiver/frequency` 可用列，缺失即写 `NR`）、`split_group_file.json`（含种子与哈希）、`final_test_freeze.json`、审计报告 |
| 通过条件 | ① 文件级划分重叠为 0；② 每类在 train/val/final test 中都有源文件（若某类源文件数不足，必须在报告中显式记录而不是静默合并）；③ final test 的 SHA256 在任何后续阶段开始前与结束时一致 |
| 停止/转向条件 | 若 DroneRFa 无法提供任何可证的会话/日期/距离/接收机信息，则**明确降级表述**：只称"文件级分组"，不得写"跨会话"；同时把外部数据（DRFF-R2、RFUAV、CageDroneRF）评估为后续阶段的数据来源 |
| 为什么排第一 | 矩阵中证据最强的两条负面结论（TVT 2020 的随机切片约 97%→跨突发约 49–50%；Sensors 2024 的同环境≈满分→换环境 81/53 与 44/1）都源于切分单位与被试单位不一致。当前 heldout 只证明文件级不重叠且已参与选型 |

## 阶段 2 `BASELINE-COMPLETE`：直接三分类与同预算 Raw-IQ 基线

| 项目 | 内容 |
|---|---|
| 目标 | 回答两个当前无法回答的问题：级联是否必要？STFT 是否真的优于同预算 Raw-IQ？ |
| 前置依赖 | `META-SPLIT` 通过 |
| 数据 | 当前 3 类（Background / DJI Phantom 4 Pro / DJI Air 2S），按 `P1_group_file` 划分，training/validation 与 final test 严格隔离 |
| 模型/基线 | ① 能量阈值（已验收，沿用阈值选择规则）；② PSD+SVM（已验收，`linear, C=0.01` 只用旧 train 拟合、旧 val 选择）；③ 直接 3 分类 2D-STFT（ResNet18 轻量档，`n_fft=512`/`hop=256`，与级联同前端）；④ 参数量匹配的 1D Raw-IQ 残差网；⑤ 已验收的级联三分类作为对照（不重训，引用既有预测） |
| 划分 | `P1_group_file` 为主口径；同时报告 `P0_random_window` 仅作复现对照 |
| 主指标 | 文件等权 balanced accuracy（主）；宏 F1、逐类召回、混淆矩阵、跨种子样本标准差；同时给出 pooled 窗口口径但明确标注为非主口径 |
| 计算成本 | 中：4 个新模型 × 3 seed × 约 5 epoch，单卡 RTX 4060 量级，预计数小时；特征张量按 split 行号缓存一次 |
| 产物 | 四个基线的同口径结果表、逐窗预测 CSV、混淆矩阵图、参数/延迟/峰值显存表、失败案例（含 −15 dB 类条件） |
| 通过条件 | ① 所有基线在同一冻结划分与同一指标口径下报告；② 1D 与 2D 基线参数量差不超过约定比例（同预算）；③ 复算脚本可独立重现结果表 |
| 停止/转向条件 | 若直接 3 分类与级联在文件等权口径上差异在噪声范围内，则结论写成"级联非必要"，并据此简化后续路线，而不是继续加模块 |
| 明确不做 | 不引入 Transformer 大模型、不引入预训练迁移、不做集成堆叠（依据矩阵 `X003` Open-RFNet 与 `M030`、`M042` 的边界） |

## 阶段 3 `MULTICLASS`：扩展 DroneRFa 更多机型与层级分类

| 项目 | 内容 |
|---|---|
| 目标 | 从"两机型"走向多类闭集与层级识别（背景/无人机 → 厂商/协议族 → 型号），使结论可与领域内 20–39 类工作对话 |
| 前置依赖 | `BASELINE-COMPLETE` 通过 |
| 数据 | 本机已具备的更多 DroneRFa 类别（按 `META-SPLIT` 的元数据登记）；类别数量以实际可得文件为准，不预设 |
| 模型/基线 | 沿用阶段 2 胜出的表征（2D-STFT 或 1D，或两者），加一个层级头；对照为扁平多分类 |
| 划分 | `P1_group_file`；报告每类源文件数，样本不足的类必须标注而不是补齐 |
| 主指标 | 文件等权宏平均 F1 与 balanced accuracy；层级错误分解（父类错 vs 子类错） |
| 计算成本 | 中到高：随类别数线性增长；建议按类别分批训练并复用冻结特征缓存 |
| 产物 | 多类结果表、层级混淆矩阵、逐类样本数与源文件数表、类别不平衡说明 |
| 通过条件 | ① 每类至少 1 个独立源文件出现在 final test；② 层级与扁平对照在同一数据同一划分下比较；③ 报告类别不平衡对宏指标的影响 |
| 停止/转向条件 | 若新增类别与已有类别在中心频率/带宽上完全绑定，先做频带捷径审计（随机平移/统一中心频率）再决定是否继续扩类 |
| 备注 | DroneRFa 公开 24 类无人机信号加背景（[DOI 10.11999/JEIT230570](https://doi.org/10.11999/JEIT230570)）；"可用类别数"必须按实际可下载/已有文件登记，不能按论文声明数写 |

## 阶段 4 `OPENSET`：多个 known/unknown 划分与校准

| 项目 | 内容 |
|---|---|
| 目标 | 把"未知类拒识"作为独立任务评价，而不是用闭集准确率代替 |
| 前置依赖 | `MULTICLASS` 通过（需要至少 5 个可留出的类别） |
| 数据 | 从已登记类别中构造至少 5 组 known/unknown 划分，按厂商、协议相近度与样本量分层；每组含代理未知用于校准，最终测试未知类隔离 |
| 模型/基线 | 闭集骨干 + 开放集头：MSP、energy、prototype（主）、OpenMax/EVT（对照）；闭集损失用 CE，另做 CE+SupCon 对照 |
| 划分 | `P1_group_file` + 每组 unknown 留出；阈值只用校准集（含代理未知），**不得接触**最终测试未知类 |
| 主指标 | OSCR、AUROC、KAR/UAR、FPR@95TPR、ECE/Brier；同时报告已知类文件等权 BA |
| 计算成本 | 中：5 组划分 × 3 seed；不引入生成式未知模型，避免额外训练成本 |
| 产物 | 每组划分的开放集结果表、校准曲线、阈值与校准集哈希、未知类混淆分析 |
| 通过条件 | ① 至少 5 组划分全部完成且阈值脚本可审计；② 校准集与测试未知类无交集（用哈希证明）；③ 已知类 BA 与开放集指标同时报告 |
| 停止/转向条件 | 若只有"未知类远离已知分布"的极端设置能拒识，或拒识完全由 SNR/功率驱动，则先修表征与捷径，不调阈值 |
| 依据 | [S3R / TIFS 2024](https://doi.org/10.1109/TIFS.2024.3463535) 与[官方代码](https://github.com/DaftJun/S3R)；[Open-RFNet / JSAC 2026](https://doi.org/10.1109/JSAC.2026.3669136)（单一 20/5 划分是其限制，不是模板）；[TCCN 2024 EVT](https://doi.org/10.1109/TCCN.2023.3327594) |

## 阶段 5 `CROSSDOMAIN`：跨会话 / 环境 / 距离 / 接收机 / 数据集

| 项目 | 内容 |
|---|---|
| 目标 | 在至少一个真实域轴上验证识别是否保持；并用探针证明模型没有依赖非目标捷径 |
| 前置依赖 | `OPENSET` 通过（或至少 `MULTICLASS` 通过，若把开放集与跨域分两篇） |
| 数据 | 优先 ① DroneRFa 内的距离/会话/室内外划分；② 外部数据：DRFF-R2（26 台个体、双接收机、多日、Wi-Fi 混合，[arXiv:2603.00106](https://arxiv.org/abs/2603.00106)）、RFUAV（约 1.3 TB、37 类型，[arXiv:2503.09033](https://arxiv.org/abs/2503.09033)）、CageDroneRF（受控 SNR/干扰/频移，[arXiv:2601.03302](https://arxiv.org/abs/2601.03302)）。任一外部数据使用前必须核对许可、标签空间与预处理一致性 |
| 模型/基线 | 阶段 2/3 的骨干 + 轻量域正则（默认不加强域对抗）；对照：无域损失、简单增强、DANN/域对抗（仅当域标签充分且域与类别不高度混杂） |
| 划分 | `P2_cross_session_day`、`P3_cross_receiver_or_distance`、`P4_cross_dataset`（先对齐到共同层级标签，再谈型号级） |
| 主指标 | 跨域文件等权 BA、宏 F1；开放集指标沿用阶段 4；**域探针**（线性分类器预测文件/接收机/日期）准确率下降幅度；捷径干预前后差值 |
| 计算成本 | 高：外部数据可能需下载与重采样；建议先做零样本，再决定是否做少样本适配 |
| 产物 | 跨域结果矩阵（域轴 × 方法）、域探针报告、频带/幅度/背景干预消融、失败案例清单 |
| 通过条件 | ① 至少一个域轴上的留出是真实可证的（不是同文件随机切分）；② 主结果在文件/会话分组口径下报告；③ 域探针显示表征未编码域身份，或明确报告未做到 |
| 停止/转向条件 | 若标签空间或预处理无法对齐，降级为"跨数据集可行性研究"并写清不可比之处；若跨域下降幅度与 Sensors 2024 量级相当，则把贡献转为"评测与可靠性研究"而非新模型 |
| 依据 | [Channel2Channel / JSAC 2025](https://doi.org/10.1109/JSAC.2025.3584434)；[跨接收机 RFFI / TIFS 2025](https://doi.org/10.1109/TIFS.2025.3630316)；[跨域 UAV RFFI / TCCN 2026](https://doi.org/10.1109/TCCN.2025.3561305) |

## 阶段 6 `STREAM-DETECT`：连续宽带流的多信号检测与定位

| 项目 | 内容 |
|---|---|
| 目标 | 从"已裁剪窗口分类"转向"连续流上的检测 + 时频定位 + 逐实例分类" |
| 前置依赖 | **必须先具备**连续宽带流数据与目标框标注（时频框 + 实例类别）。当前项目不具备该条件，因此本阶段默认不可启动 |
| 数据 | 真实多源空口录制；数字叠加只能作为受控对照并显式标注。可评估 CageDroneRF 的检测标注工具（其标注会随频移等增强同步重算） |
| 模型/基线 | 盲检测（GoF/能量/谱峭度）→ 时频实例检测（YOLO 类）→ 逐实例分类（复用阶段 3/4 的编码器与开放集头）。对照为 TCCN 2022 的两条路线：GoF+DRNN 与 YOLO-Lite |
| 划分 | 按原始录制会话分组；多源与单源不得混在同一集合 |
| 主指标 | 实例级 mAP、检测 mAP@IoU、实例分类 F1、未知信号召回、误报/小时；端到端延迟与参数/显存 |
| 计算成本 | 高：需要标注与检测训练，且窗口长度会引入不可消除的检测延迟 |
| 产物 | 实例级检测与分类结果表、时频框可视化、未知 RF 入口（保留无法归类的片段）的评估报告 |
| 通过条件 | ① 存在真实多源标注（或明确以受控叠加为限并写清外推边界）；② 检测与分类分开报告；③ 端到端误报/小时被测量 |
| 停止/转向条件 | 若无法获得目标框标注，则本阶段无限期推迟——**不得**把已裁剪单信号的 3 分类问题包装成目标检测 |
| 依据 | [TCCN 2022 联合检测分类](https://doi.org/10.1109/TCCN.2021.3099114)；[SMNet / TCCN 2025](https://doi.org/10.1109/TCCN.2025.3537100) |

## 暂缓项：噪声方式实验（待用户以后恢复）

| 项目 | 内容 |
|---|---|
| 状态 | **用户已明确暂缓，不进任何立即执行阶段**。本路线图只登记，不排期，不自动开始 |
| 恢复后的目标 | 在同一冻结划分下比较不同噪声方式（人工 AWGN vs 真实背景/干扰录制 vs 实测距离造成的 SNR 变化）对识别与拒识的影响 |
| 恢复后的数据 | CardRF（含 Bluetooth/Wi-Fi 的真实室外数据，[DOI 10.21227/1xp7-ge95](https://doi.org/10.21227/1xp7-ge95)）；CageDroneRF 的受控 SNR/干扰/频移基准 |
| 恢复后的主指标 | 分层 SNR 曲线的文件等权 BA、误报/小时、开放集指标；必须与"同环境低 SNR"分开报告 |
| 恢复条件 | 用户显式授权；且 `META-SPLIT` 与 `BASELINE-COMPLETE` 已通过（否则噪声差异与切分差异无法解耦） |
| 为什么暂缓 | 当前最优先缺口是划分独立性与 final test 冻结；矩阵中 TVT 2020 与 Sensors 2024 都显示"噪声/条件轴"只有在切分正确时才可解释 |

## 阶段总览

| 阶段 | 依赖 | 是否可立即开始 | 关键闸门 |
|---|---|---|---|
| `META-SPLIT` | 无 | **是（唯一推荐）** | 划分重叠为 0 + final test 哈希冻结 |
| `BASELINE-COMPLETE` | `META-SPLIT` | 否 | 同预算对照 + 同口径报告 |
| `MULTICLASS` | `BASELINE-COMPLETE` | 否 | 每类至少 1 个 final test 源文件 |
| `OPENSET` | `MULTICLASS` | 否 | ≥5 组 known/unknown + 校准集与测试未知类隔离 |
| `CROSSDOMAIN` | `OPENSET` | 否 | 至少一个真实可证域轴留出 |
| `STREAM-DETECT` | 连续宽带流 + 目标框标注 | 否（当前不具备） | 存在真实标注，检测与分类分开报告 |
| 噪声方式实验 | 用户恢复授权 | 否（用户暂缓） | 用户显式授权 + 前两阶段通过 |

**唯一推荐的下一实验任务：`META-SPLIT`。** 本表与 `00_前沿文献矩阵与项目差距报告.md` 第 0.4 节、第 7 节结论一致。
