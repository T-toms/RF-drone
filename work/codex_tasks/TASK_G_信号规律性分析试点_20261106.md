## 0. 背景（为什么要做）

用户的规则：先看整段长时谱，**有特征的信号都要截取**（不限于图传）；**孤立的、看不出分布规律的信号不截**。
难点：跳频信号在短时间内是突然出现的，**单个信道**的出现率可能很低（< 30%），但**整个跳频信号**在长时间上是有规律的：
- 时间规律：突发起始时刻间隔固定（或是某个基本周期的整数倍），驻留时长固定；
- 频率规律：只在一组固定信道上跳，信道间隔固定，每个信道反复被访问；
- 形状一致：同一信号的突发带宽、时长、功率接近。
所以不能按"每个频点出现率"判断，要先把时频图上的**每个突发**检测出来，按形状把突发归成"信号"，再对每个信号整体判断规律性。
已有的 1 ms 缓存（任务 A）时间分辨率不够（突发约 0.5–2 ms），必须从原始 IQ 重新做细时频分析。

## 3. 方法

### 3.1 突发检测
- 每段（data 50 ms；v3 每个连续块）做 STFT：NFFT = 1024、Hann、hop = 512（data：120 kHz / 4.2 µs；v3：97.7 kHz / 5.1 µs）。只在可用掩膜内（|f_norm| ≤ 0.45）。
- 先对任务 E 的稳定细线频点（`lines_classified.csv` 中 `persistent_tone_candidate`）±150 kHz 置为 floor，不让它们参与检测。
- 二值化：功率 > floor + 10 dB。形态学闭运算（时间 3 帧 × 频率 2 bin）后取 8 连通域。连通域面积 < 6 个像素的丢弃（噪声）。跨相邻段边界的连通域要合并（data 段连续）。
- 宽带长时信号（如图传）可能把多个突发连成一大块，记录即可，不强行拆分；但若一块的时间跨度 > 20 ms，按"时间上占用率 < 50% 的列"切开成多个突发。
- 每个突发记：t_start_ms、duration_ms、f_lo/f_hi/f_center_MHz、bandwidth_MHz、峰值和平均功率（dB above floor）、所在 epoch。

### 3.2 把突发归成"信号"
- 特征：log(bandwidth)、log(duration)、平均功率。用 DBSCAN（自行实现或 sklearn 若已安装；没有就写简单的网格/层次聚类），标准化后 eps 自定，**在报告中写明参数**并给一张散点图（bandwidth × duration，颜色 = 聚类）。
- 同一类再按频率细分：中心频率差 < 0.5 × bandwidth 的视为同一"信道"。一类信号 = 一组信道。

### 3.3 每个信号的规律性指标
- `n_events`、每个 epoch 的事件数、覆盖率（含 ≥ 1 个事件的 100 ms 块比例）、在 50 ms 窗中的出现率（10/20/30/40/50 ms 各算一次）。
- **时间规律**：起始时刻的间隔 IAT。在 IAT 及所有两两时间差（≤ 200 ms）的直方图中找基本周期 T0（允许事件漏检：用"多数 IAT 是 T0 的整数倍"的 T0）。`time_regularity` = IAT 落在 k·T0 ± 3% 的比例。若信号在多个信道上跳，**合并所有信道**计算一次，并对每个信道单独再算一次。
- **频率规律**：信道数、相邻信道间隔的众数与其占比（`spacing_regularity`）、每信道被访问次数。
- **形状一致性**：duration、bandwidth 的变异系数 CV。
- **跨 epoch**：两个 epoch 是否都出现；两个 epoch 的 T0、信道集合是否一致。

### 3.4 分类（阈值写成常量，报告中给出每个信号的全部指标，方便以后调整）
- **有特征**（featured），满足任一：
  a. 持续型：50 ms 窗出现率 ≥ 0.9；
  b. 周期型：n_events ≥ 20，`time_regularity` ≥ 0.7，CV(duration) ≤ 0.3，两个 epoch 都出现；
  c. 跳频型：信道数 ≥ 3，`spacing_regularity` ≥ 0.6，每信道访问 ≥ 3 次，n_events ≥ 20，CV(bandwidth) ≤ 0.3，两个 epoch 都出现。
- **孤立/无规律**（isolated）：n_events < 5；或不满足 a/b/c 且 `time_regularity` < 0.4 且 `spacing_regularity` < 0.4。
- **待人工看**（review）：其余。
- **环境候选**：在试点中，若 #8 背景里有同形状（bandwidth、duration 各差 < 20%）且中心频率差 < 1 MHz 的信号，在无人机录制里标 `also_in_background=True`（只标记，不改分类）。

### 3.5 每个录制的"有特征频带"
- 有特征信号的 [min f_lo, max f_hi] = `featured_span_MHz`；所有有特征信号带宽之和 = `featured_total_bw_MHz`（各信道合并后去重叠）。两者都输出，供后面决定"截一整段宽频带"还是"分别截几个子带"。
