# 任意信号分析界面架构（INFER-UI1）

## 产品目标

提供一个仅监听本机 `127.0.0.1` 的中文浏览器界面。用户可以选择本机IQ文件或上传文件，检查格式和采样参数，按1,000,000复数点流式切窗，并调用已经验收的三级串联模型。主界面回答：分析了多少窗、各窗是否为背景/Phantom/Air2S、三个模型是否一致、信号整体以什么类别为主，并展示时间轴、波形、幅度和STFT。

“任意”表示输入文件来源和长度不固定，不表示模型能够识别任意采样率、任意射频前端或未知无人机。分类只在用户确认100 MS/s且I/Q结构可解析时启用；其他信号只能检查/预览并显示不兼容原因。

## 架构

- `signal_analyzer_core.py`：输入探测、流式读取、窗口计划、六个冻结检查点加载、三套级联推理、三模型多数决、文件级汇总、图片和CSV/JSON/Markdown导出。
- `signal_analyzer_server.py`：标准库 `ThreadingHTTPServer`，静态页面和JSON API；后台单GPU作业队列、进度、取消、结果查询；本地路径白名单和流式上传。
- `signal_analyzer_web/`：中文HTML/CSS/JavaScript，不依赖CDN或外部网络。
- `launch_signal_analyzer.ps1`：固定使用项目 `.venv`，默认 `127.0.0.1:8765`，可传端口、输出根和允许目录。

API至少包含：`GET /api/health`、`POST /api/inspect`、`POST /api/analyze`、`GET /api/jobs/<id>`、`POST /api/jobs/<id>/cancel`、静态结果文件读取。服务器只返回允许根目录和当前分析产物内的文件。

## 分类与汇总

不向用户信号添加AWGN。每窗使用n_fft512/hop256的clean前端。每个训练种子按现有级联阈值单独输出最终类别；三种子最终类别多数决。若三票分别为Background/Phantom/Air2S，则显示“模型意见不一致”，不强制归到已知类。

文件级标题是“主导结论”，不是经过额外训练的事件检测器。无人机窗占全部已分析窗严格超过50%时显示“无人机占主导”；背景严格超过50%时显示“背景占主导”；其余显示“混合或不确定”。同时始终显示“是否出现过无人机窗”和无人机窗比例，避免多数规则掩盖短时片段。

## 输入与资源

HDF5 MAT和NPY必须切片读取，不一次性加载多GB文件。NPZ压缩文件若无法内存映射，检查大小并明确提示风险。裸二进制必须由用户指定dtype、字节序、complex或交织IQ及I/Q顺序。短于一窗的数据不填零，直接说明不满足当前模型输入。批量推理保持batch=4，六个模型只加载一次；同一时间只执行一个GPU作业。

## 结果边界

logit margin只称“决策分数”，不能标为置信概率。输出中保存模型哈希、配置哈希、解析参数、窗口起止样点、每种子两阶段logits/margin、是否执行第二阶段、集成标签和文件汇总。未知型号可能被迫分到现有类别，页面必须持续显示这一限制。
