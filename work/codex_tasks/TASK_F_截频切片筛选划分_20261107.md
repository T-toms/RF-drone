## 3. 截取（每个连续块/每个 run 独立处理）

用 `lab_preproc.py` 已有函数；若需新写，放 `work/crop_slice_20261107/crop.py`。

1. 下变频：`x · exp(−j2π (f_center − fc) n / fs_in)`，f_center = 2430（2.4G）或 5800（5.8G）MHz。
2. 重采样到输出采样率（`scipy.signal.resample_poly`，零相位、线性相位 FIR）：
   - data 2.4G：122.88 → 61.44，`up=1, down=2`；
   - data 5.8G：122.88 → 100，`up=625, down=768`；
   - v3 2.4G：100 → 61.44，`up=384, down=625`；
   - v3 5.8G：100 → 100，不重采样。
3. **统一终端滤波器**（关键）：每个频段设计**一个**线性相位 FIR 低通，在输出采样率下对**所有来源、所有样本**同样施加。2.4G：通带 ±25.0 MHz（波动 ≤ 0.05 dB），阻带 ≥ ±27.5 MHz、衰减 ≥ 70 dB；5.8G：通带 ±45.0 MHz，阻带 ≥ ±48.0 MHz、衰减 ≥ 70 dB。目的是让频带边缘形状只由这个滤波器决定，而不是由两台接收机各自的滤波器决定。系数存 `filters.npz`，参数写 config。
4. **统一陷波**（同一频段所有样本相同）：
   - 陷波频点集合 = 截取频段内的：(a) 各来源的中心频点尖峰（2.4G：2440.00、2450.00 MHz；5.8G：5800.00 MHz）；(b) `lines_classified.csv` 中 `classification == persistent_tone_candidate`、出现在 ≥ 2 个录制/会话中的稳定线（按 ±20 kHz 合并；预期 2.4G 至少含 2426.88 MHz）。`data/` 2.4G 的 2400.00、2457.60 和 5.8G 的 5740.00 在频段外，由带通滤除，不另陷波。
   - 每个频点一个固定陷波半宽：max(2 × 该线 `width_khz` 的中位数, 60 kHz)，中心频点尖峰用 max(2 × 宽度, 100 kHz)。用 `lab_preproc.py` 的 notch（复下变频 + 零相位高通）实现。**所有样本用完全相同的频点与半宽**，即使某个来源本身没有这条线。
   - 最终陷波表写 `notch_table.csv`（band, freq_mhz, half_width_khz, origin = fc_spike/stable_line, 出现在哪些来源）。
5. 块边缘：滤波和陷波会在每个连续块两端产生暂态。每块两端各裁掉“整条链路中最长滤波器的长度”对应的输出样本（至少 0.2 ms），裁掉部分不进入任何片段。实际裁剪长度写 config。
6. 存储：每个连续块一个 `.npy`（complex64，**不做任何归一化**），文件名 `<band>/<dataset>/<group_id 去掉非法字符>__blk<k>.npy`；另存 `blocks.csv`：block_file, dataset, band, label, model, state, bw_label, group_id, source_paths（分号分隔）, fs_out, n_samples, t0_in_source_ms（块起点在原录制/原始文件中的时间）, power_db_median（块内 1 ms 平均功率的中位数）。
7. 断点续跑：每块写完再写一行到 `blocks_done.txt`；重跑跳过已完成的块。长时间运行放后台进程，日志写 `run.log`。

## 4. 切片

对每个 L ∈ {10, 20, 30, 40, 50} ms：
- 每个块内**不重叠**地从块起点开始切，步长 = L；不足一个 L 的尾部丢弃。片段不得跨块。
- 输出 `index_L<L>.csv`：sample_id, block_file, start, n_samples（= L × fs_out / 1000，整数）, dataset, band, label, model, state, bw_label, group_id, split, 以及 §5 的筛选列。
- 注意：v3 每块约 100 ms，L=50 时每块只出 1 个片段（剩下不足 50 ms），如实统计。

## 5. 筛选（老师的规则，沿用 v3b，只对无人机样本；背景一律保留）

- 先在**截取后的 IQ 流**上为每个无人机块计算 1 ms cell 特征：NFFT 使 bin ≈ 120 kHz（2.4G：512 点 @ 61.44 MS/s；5.8G：1024 点 @ 100 MS/s 即 97.7 kHz，写明），Hann，不重叠，相邻 4 bin 平均折叠的做法改为**不折叠**；cell = 1 ms 内各帧的 mean/max/min（dB）。陷波频点 ±半宽 的 bin 视为环境 bin。
- 把 `screen_lab_windows_v3b_20261031.py` 的判定（`lack_feature`、`primary_weak`、`power_shift`、`floor_raised`、`interference`，阈值与 v3b 相同；`ref = recording`）移植到这些 cell 上，L 改为 10/20/30/40/50。由于频段已固定，`interference`（子带外干扰）改为只看截取频段内、不属于本录制任何子带的新增能量，判据与 v3b 相同。
- 每个片段写 5 个标记列和 `keep`（= 五个标记全假）。背景样本标记全为 False、keep = True。
- **不删除任何片段**，只标记；训练时再按 keep 过滤。

## 7. 验证（`verification.json`，每项 pass/fail + 数值）

1. **泄露检查**：每个 group_id 只出现在一个 split；所有 L 的索引中同组片段 split 一致；同一 block_file 的片段 split 一致。
2. **片段边界**：所有片段 `[start, start+n_samples)` 在其块内；无跨块片段。
3. **滤波器**：每个（来源采样率, 频段）的整条链路做合成单音测试：通带内（距边缘 ≥ 1 MHz）单音幅度误差 ≤ 0.1 dB、频率误差 < 1 kHz；阻带外 3 MHz 单音被抑制 ≥ 60 dB。
4. **陷波**：每个来源随机 3 个片段（种子 20261107），每个陷波频点残留 ≤ 3 dB（相对 ±1 MHz 局部中位数）；陷波外 ±(0.2–2 MHz) 频点功率变化 |Δ| ≤ 0.1 dB。
5. **底噪形状一致性（重要）**：对每个来源（data 2.4G、v3 背景 2440、v3 背景 2450、v3 无人机 2440、data 5.8G、v3 背景 5800、v3 无人机 5800），取截取后功率最低的 10% 的 1 ms cell，算频段内平均谱（去掉陷波区），各自归一化到中位数 0 dB。画在同一张图 `floor_shape_<band>.png`，并报告每两来源之间的最大差值（dB）和出现位置。**差值 > 1 dB 不要自行修正**，在报告中写明位置（多半在频段边缘），作为是否需要再收窄频段的依据。
6. **重算一致**：随机 3 个片段，从原始文件独立重算整条链路，与存储结果的最大相对误差 < 1e-4。
7. **计数**：每个 L × split × (dataset, band, label) 的片段数、keep 后片段数、秒数；每个 model 在各 split 的片段数。
8. 原始数据根运行前后文件数与最新修改时间不变。
