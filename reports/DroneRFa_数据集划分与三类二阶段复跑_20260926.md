### 1.3 必须保留的边界

1. MAT 文件头 `Created on` 时间与本地 RAR 头 `HTIME` 只是**文件时间/批次代理**（两者相差 ≤ 2 秒，RAR 时间可能继承原文件时间），**不是**独立证明的无线电采集时间或会话 ID。13 类各有且仅有一个时间簇，因此本划分不能声称“跨采集会话”。

3. 早期 T0000 候选多出一个不同文件日期（2022-12-13）且同时更换了频段，无法隔离日期效应，因此未下载、未纳入本次划分。
4. 窗口级随机拆分被明确禁止：任何随机拆分都会让同一源文件的相邻 10 ms 片段同时出现在训练和测试中。

### 4.2 窗口规则

- 读取 RF0 的 I/Q 两列实数，按 100 MS/s 复数基带处理。
- 窗口 = **1,000,000 采样 = 10.0 ms**，**非重叠**，步长 = 窗长。

- `window_index` 是文件内从 0 起的全局窗序号；`block_index` / `window_in_block` 是同一窗口在 10M 块内的等价定位。

## 10. 术语速查

| 术语 | 含义 |
| --- | --- |
| MAT 文件 | MATLAB/HDF5 容器，含 RF0 的 I/Q 两列；本项目窗口为 1,000,000 采样（10 ms，100 MS/s） |
| 源文件级最小分组 | 同一 MAT 的所有窗口只能进同一个角色；防止同源近重复跨 split |
| `development_test` | 新十类 S0110/S0111，同批次文件级留出，可作开发主指标 |
| `development_test_exposed` | 旧三类 S0110/S0111，此前已用于实验，只能作已暴露对照 |
| stage1 margin | `float32(logit_drone) − float32(logit_background)`，> 0 才执行阶段 2 |
| 按文件等权准确率 | 先算每个源文件的窗口准确率，再对三类取等权平均（本项目主指标） |
| pooled accuracy | 忽略文件归属、直接统计全部窗口的准确率（辅助指标） |
| 文件时间代理 | MAT 文件头 `Created on`（及 RAR `HTIME`），只能说明批次先后，不构成采集会话证据 |
| clean 条件 | 不额外注入人工白噪声，直接使用原始 RF0 记录；不等于现场绝对 SNR |
