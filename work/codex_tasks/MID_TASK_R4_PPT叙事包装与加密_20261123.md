## 1. 通用写作规则

### 1.1 叙事结构（所有“研究环节”页）

R3 的五个小标题（怎么发现的 / 怎么证实的 / 依据 / 怎么解决的 / 结果与留下的问题）**全部改掉**，换成：

| 小标题 | 写什么 |
|---|---|
| **研究背景** | 当时在做哪一步、为什么做；必要时自然带出“这一步延续了前面哪项观察” |
| **现象** | 观察到的结果，给出数字 |
| **分析与验证** | 原因分析，以及验证原因的对照实验；文献放在这里，按 §1.4 的写法写 |
| **改进方法** | 具体做法和参数 |
| **效果与启示** | 改进后的数字，以及由此引出的下一步（下一页的入口） |

每块用完整的句子写，块与块之间要有“因此、由此、在此基础上、进一步”这类因果衔接，不能写成各自独立的条目。

**措辞示例（照这个方向改）：**

| 不要这样写 | 改成这样 |
|---|---|
| 模型依赖 WiFi / 模型靠 WiFi 判断 | 模型的判断受到环境 WiFi 信号的影响 |
| 首轮误报 0.4% 是假象 | 首轮总体误报率较低（0.4%）；按数据来源分别统计后，发现不同来源的检出率差异明显 |
| 误报 100% | 初始模型对该设备的无信号数据全部判为有无人机（误报率 100%） |
| 更正原假设 | 进一步实验表明…… |
| 数据有缺陷 / 数据有问题 | 实测数据的特点 / 数据质量核验 |
| 失败、错误 | 尚未解决 / 需要进一步处理 |
| 问题链 x/9 | 页右上角改成所属阶段，例如“公开数据集阶段”“实测数据阶段 · 环节 3” |

### 1.2 数据名称（听众视角）

| 不许出现 | 改成 |
|---|---|
| 城区、家居、城区接收机、城区背景、城区无人机 | **真实环境数据**（另一台接收机在室外和室内居家等日常环境中录制）；“真实环境背景”；“真实环境数据中的无人机” |
| 实验室接收机、data/ | **实验室数据**；需要指设备时写“实验室数据所用的接收机” |
| 接收机 A / B、bgA、v3、evo2pro_v3 等 | 按上两行替换；型号写正式名称，例如“EVO II Pro V3” |
| “城区背景叠加到实验室背景上的测试集” | “模拟测试集：真实环境背景叠加到实验室数据的无信号频段上（不含无人机）” |
| 只有一段录音的机型（不解释） | 第一次出现时解释一句：“这类机型只能放在训练集或测试集其中一边，无法按录音划分评估” |

**第一次出现“接收机”时**解释一句：接收机就是录制无线电信号的设备，类似于录音机；不同接收机自身的电子噪声和杂散信号略有差异。

R3 §1.1 的禁用词表继续有效。另外再禁用：城区、家居、捷径、作弊、假象、失败。

### 1.3 信息密度和版式

- **研究环节页：**
  - 正文 450–600 字；
  - 3–4 个内容块，外加 1–2 张图；
  - 正文 11–12 pt，图注 9–10 pt，最小 9 pt；关键数字 20–24 pt。
- **方法页、计划页：** 正文 500–700 字，必须分块。
- **留白：** 每页内容区留白不超过约 15%。R3 第 16 页那种下方大片留白不允许。
- **图：** 能用图就配图，文字放在图旁边解释，不是用图代替文字。
- **逐页备注：** 全部重写，每页 200–300 字，口语化，按“这页讲什么 → 关键证据 → 怎么引到下一页”。

### 1.4 文献写法（重点）

引用一篇文献时，用 1–3 句话写出三件事：

1. 它做了什么；
2. 得出了什么结论（带数字）；
3. 与本项目的关系：为什么在这一步提它、拿它和本项目的哪一点对照。

每页的文献信息放在“分析与验证”块里，或者放在文献原图旁边的说明里；页底只放出处，例如“Soltani 等, IEEE TVT 2020”。

### 第 3 页　研究背景、目标与技术路线

- **左上块“研究背景”**（约 120 字）：
  - 消费级无人机越来越普及，低空安全需要先“发现”、再“认出”无人机。
  - 射频检测接收的是无人机与遥控器之间的通信信号，不依赖光照和视线。
  - 难点有两个：
    - 2.4 GHz、5.8 GHz 是公共频段，WiFi、蓝牙也在其中，干扰信号和无人机信号同时出现；

- **左中块“两阶段任务与指标”**：同 R3（第一阶段：各机型漏检 ≤1%、背景误报 ≤1%；第二阶段：0、−5、−10、−15 dB 平均准确率 ≥95%）。

### 第 5 页　公开数据集上的两项观察：信号周期与频率位置

左右两栏，每栏按 §1.1 的五个小标题写。

**左栏“信号周期与观测窗长”**

- **研究背景**：基线漏检在时间上周期性出现。
- **现象 / 分析与验证**：
  - Matrice 100 每 14 ms 才发射一次 1–2 ms 的突发；
  - 10 ms 窗口约 29% 恰好落在两次发射之间的空隙，窗口里没有无人机信号。

- **改进方法**：

### 第 13 页　环境干扰的对称叠加

- **研究背景**：补入同设备背景后，真实环境数据中的无人机检出仍只有 62%，训练集中缺少“带环境干扰的无人机”。

### 第 15 页　时频图与手工特征融合的效果评估
