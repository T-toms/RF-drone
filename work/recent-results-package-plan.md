# DroneRFa 近期成果包整理方案

目标成果包按研究阶段整理，不复制约 23GB 的 MAT 数据本体，不包含缓存、临时测试、重复渲染页、逐轮训练检查点和中断日志。

成果包包含：

- 数据准备、迁移与冻结索引；
- 第一阶段传统基线、噪声训练评价、FFT 点数比较及正式模型；
- 第二阶段机型识别结果及正式模型；
- 两阶段串联三分类结果；
- 任意 IQ 信号分析界面的程序、网页、启动脚本和验证材料；
- 训练、评价、验证程序与依赖说明；
- 参考论文、文献综述和阶段验收记录；
- 来源、用途、大小和 SHA256 清单。

执行脚本：`work/package_recent_results.ps1`。
