## 1. 版式与写作规则（本轮核心）

### 1.1 版式

| 项目 | 要求 |
|---|---|
| 图文比例 | 每页内容区 **至少一半是图**（流程图、结构图、示意图、数据图、文献原图） |
| 正文字数 | 每页正文 **≤ 220 字**（不含图内标注、图注、表格）；方法页、特征页可到 280 字 |
| 字号 | 正文 14–16 pt；图注、表格 ≥ 11 pt；关键数字 24–32 pt。全篇最小 11 pt，不再用 9 pt |
| 块数 | 每页 2–3 个内容块，块之间留白清楚；不要把页面塞满 |
| 标题 | 标题直接写结论或主题，例如“同设备背景构造：误报 100% → 0%” |
| 页底出处 | 文献出处 10–11 pt，放在内容区右下，不压页脚线 |
| 删除的部件 | 层次进度条、浅蓝承接条、深蓝结论条、“环节 x”、页内五段式小标题、段间箭头 |
| 备注 | 每页 150–250 字，书面但顺口，可以直接照着讲 |

### 1.2 写法

- 用陈述句写结果和方法，不写“我们发现……然后……于是……”这类过程叙述。
- 每个专业词第一次出现时，用一句小字解释（例如“时频图：横轴为时间、纵轴为频率、亮度表示能量的图像”）。
- **数字只用本文和 R3/R4 中已有的**，不编造。
- 文献的写法按 R4 §1.4，但压缩成一行：“谁 + 做了什么 + 结论数字”。与本项目的关系放在正文里用半句话带出。

### 1.3 制图

- 优先用 PPT 原生形状，方便用户以后修改；数据图用 matplotlib 出 300 dpi PNG，脚本保存为 `ppt_build/r5_figs.py`。
- 中文字体微软雅黑，西文 Arial；线条深灰；填充只用模板蓝系，橙色 #F0A30A 只用于强调。
- 不用图标、剪贴画、阴影、渐变、3D。
- 每张新图里的文字都要检查禁用词（R4b 的教训：图片里的字也要逐张查）。
