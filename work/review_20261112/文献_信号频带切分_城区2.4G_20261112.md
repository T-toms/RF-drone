## 一、问题复述

每个 20 ms 窗口做宽带时频图（城区 250 MS/s、中心 2440 MHz；实验室 122.88 MS/s、中心 2400 MHz）。目标是对每个信号输出**一个频率区间**，时间上取整个窗口（不要逐突发框）。现有检测器：局部平滑 → 逐频点底噪 → k = 6 dB 门限 → 形态学 → 连通域 → 投影到频率轴 → 间隙 < g MHz 的合并。失败的原因：城区 2.4G 的无线网（1/6/11 信道，20 MHz OFDM，突发包，几乎一直都有）和无人机图传（10/20/40 MHz OFDM）以及跳频控制突发（约 1–2 MHz × < 1 ms）在频率上相邻或交错，“投影 + 取并集”就把它们并成一个 60–68 MHz 的频带。

**根本原因**：频率投影只用了“这个频点在不在某个时刻有能量”，丢掉了“这些频点是不是在**同一时刻**一起有能量”。下面的文献基本都可以按“补回哪种信息”来归类。

**无人机方向的共同点**：还没有找到哪篇论文专门做“在城区无线网背景下，按频率区间整段切出无人机频带”。现有做法分三类：(1) 逐突发画框，无线网单独作为一类（Basak、WRIST、Sci. Rep. 2026、Mendeley、RFUAV）；(2) 按带宽、调制规则判断（Ezuma：≥ 20 MHz 判为 Wi-Fi，待核实）；(3) 用循环平稳特征区分（Kaplan 2021，针对跳频遥控器）。**按频率区间整段切这件事本身，需要我们自己设计。**

### C. 城区 2.4G 无线网的占空比（和“共同起落”想法的失败模式有关）

- 用 USRP 做的 2.4G 占用测量：**用普通能量检测时，1 信道一周内每天全天都显示 100% 占用**；用自相关方法时，占用随一天的时段变化（检索摘要）。
- 高时间分辨率测量得到的占空比只有 7.4%（1 信道）、11.5%（12 信道）（检索摘要）。
- PoWiFi（arXiv 1505.06815）：繁忙办公室里 1/6/11 信道的累计占用约 90%。
- 结论：无线网“看起来一直都在”，很大程度上是**时间分辨率不够**造成的。我们一帧只有几微秒，单个包的边界是能看到的。这一点对“共同起落”想法有利（见第三节）。

## 三、评估“共同起落”（时间上同时开、同时关）的想法

### 3.1 有没有文献支持

**有，而且是三条独立的线索：**
1. **频谱测量**：Tsakalidis 等 2014（A10）就是“对频点功率时间序列算相关，相关性高的连续频点聚成一个频带，在信道边界处相关性急剧下降”，用的门限是 0.75。Ashdown 2024（A11）也构建了频点间的相关矩阵。不同的是，他们的时间尺度是分钟级，我们是微秒到毫秒级。
2. **听觉场景分析**：Hu & Wang 2007（A16）的“共同起落”原则，即同一个声源在各频率上同时起、同时止。它检测的是**起止边沿**，不是用整段相关，我们可以直接借用。
3. **跳频分选**（A17）：同一网台的跳在时间上首尾相接；按起止时间聚类来区分不同的源。

从物理上看：一个 OFDM 包的所有子载波同时开、同时关，功率电平也一起变；多个 AP、终端和无人机之间的时序互相独立（CSMA 只让 Wi-Fi 之间错开，并不和无人机图传同步）。所以**同一个发射源内部的频点相关性高，不同源之间相关性低**，这个前提是成立的。

**变体**（文献里出现过的，或者可以直接迁移的）：
- (a) 相邻频点的相关系数沿频率排成一条曲线，在曲线的低谷处切开（A10 的做法，相当于沿频率轴做变点检测）。
- (b) 全部频点两两相关 → 相似度图 → 谱聚类或归一化割，并且加上“频带必须连续”的约束。
- (c) 只比较**起止边沿**（功率对时间的导数），不用整段相关（A16）。对于长时间一直开着的源更稳。
- (d) 非负矩阵分解 V ≈ W·H（A15、A16）：等于把“共同起落”写成一个生成模型，**能处理频率上重叠的情况**（功率近似相加）。每个分量的 W 的非零范围就是它的频带。
- (e) 先剔除一类再看剩余部分（Airshark A13 先剔除 Wi-Fi 样本）。

### 3.2 失败模式（要在试验里专门测）

1. **长时间一直开着的源**：如果无人机图传在 20 ms 内几乎一直开着，它的频点时间序列接近常数，相关系数是噪声主导（分母很小）。对策：用功率电平的起伏（衰落、帧间隙）而不是 0/1 的开关；或者把“占空比接近 1 的连续频点”单独作为一类，用变体 (c) 或频谱形状来定边缘。
2. **同一信道上有多个 AP，合起来接近 100% 占用**：同一信道的不同 AP 占的频点相同，切出来本来就该是同一个 20 MHz 频带，这不算错。但不同 AP 的包功率不同，会在包的边界处一起跳变，所以起止边沿 (c) 仍然有效。真正的问题是**这个 20 MHz 频带和无人机图传在频率上重叠**的时候。
3. **频率重叠**（Wi-Fi 信道和图传部分重叠）：重叠区的频点是两个过程叠加，和两边的相关性都是中等，(a)(b) 会把重叠区随便分给一边，或者单独切成一段。只有 (d) NMF 或者循环平稳特征（候选 C）在原理上能分开。
4. **跳频控制突发**（1–2 MHz × < 1 ms）：每个频点只亮一下，和别的频点几乎不同时亮，相关性约等于 0，按共同起落会被切成很多碎带。要单独处理：先识别出“短而窄、频率在变”的块，按跳频分选的思路（A17：时间首尾相接、驻留时间相同）把它们归成一个跳频集合，集合在频率上的总范围作为一个频带。内部可以用逐突发的块，**输出仍然是频率区间**，不违反用户的要求。
5. **低信噪比或很短的包**：单个窗口里有效的开/关事件太少，相关估计方差大。
6. **Wi-Fi 信标常用 802.11b DSSS（约 22 MHz 宽，没有循环前缀）**：形状、循环特征都和 OFDM 不同。这是标准常识，不是来自上面的文献；会影响候选 C。
7. **接收机自身的谱线、镜像、AGC 跳变**：AGC 跳变会让整个频段的功率同时变化，造成“全频段一起起落”的假相关。要先去掉每帧的公共增益（例如减去每帧的中位数），这是一种控制手段。

### 3.3 其他思路的文献评价

- **频谱形状 / 边缘检测**（A1、A2）：只能处理相邻、有功率台阶的情况；对 20 ms 平均谱来说，稀疏的 Wi-Fi 包会被平均得很弱。可以改用“只在该频点活跃的帧上平均”的条件谱，或者高百分位谱，再找边缘，作为辅助信息（边缘候选位置）。
- **循环平稳**（A12、A14）：DOF 说明可以按信号类型给出各自占用的频谱，而且能处理重叠。但 B8 提醒：简单的循环前缀自相关通常分不开无人机和 Wi-Fi。所以必须用**各自的循环频率**（Wi-Fi 250 kHz，短保护间隔时约 277.8 kHz；无人机的符号长度要先在实验室纯净录音上测出来），而不是笼统地判断“有没有 OFDM”。
- **已知的 Wi-Fi 信道栅格**（1/6/11 信道中心 2412/2437/2462 MHz，中国还有 13 信道）：这是很强的先验，可以作为切分的候选边界，或者用来给切出的频带打“疑似 Wi-Fi”的标签。但不能单靠它，因为无人机图传也可能正好落在这些位置。
- **减去背景占用图**：同一地点的背景录音只能给出“哪些频率平时有 Wi-Fi”，而无人机来时 Wi-Fi 还在，所以不能从时频图里直接减掉。只能当作先验用（Airshark 的“先剔除 Wi-Fi”是在样本级做的，要能识别出 Wi-Fi 样本）。
- **深度学习分割**（A3、A8、A9）：效果最好，但要标注数据；B6 说明只用合成数据训练，到真实 Wi-Fi 上会失效。可以作为第二步，用下面的合成评测集来训练。

## 四、建议试点的算法（2–3 个）

所有候选的输出格式统一：每个窗口一组 [f_lo, f_hi]，再加上每个频带的占空比、平均功率、（可选的）Wi-Fi 可能性。

**候选 0（基线，最便宜）：块的频率范围先聚类，再合并**
在现有检测器里，连通域之后**不再取并集**，而是把每个块的 (f_lo, f_hi) 当成二维点做聚类（DBSCAN 或众数）。同一 Wi-Fi 信道的所有包，频率范围几乎一样，会聚成一簇；图传是另一簇。每簇取中位数作为频带。缺点：如果形态学已经把 Wi-Fi 包和图传连成一块，就救不回来。所以要把时间方向的闭运算缩小，并且用 A3 提到的“矩形扩展”避免把两个块粘在一起。

**候选 A（主推）：按共同起落沿频率轴切分**
1. 频率合并到约 0.25–0.5 MHz 一格，时间按约 10–50 µs 平滑，得到功率（dB）矩阵 P(f, t)；每帧减去全频段中位数，去掉 AGC 和公共增益的影响。
2. 只保留现有检测器判为“有能量”的频点范围（底噪门限保持不变）。
3. 每个频点算两种时间序列：功率序列，以及起止边沿序列（功率对时间的差分，正、负分开）。
4. 相邻频点的相关系数排成曲线 c(f)，在低谷处切开（A10 的做法；可以用变点检测或门限，例如 0.5–0.75，要在合成集上调）。另一种做法：全部频点的相关矩阵 → 谱聚类，并加上频带连续的约束。
5. 后处理：切出的段之间如果相关性高，就并回去（例如被 DC 空子载波或深衰落切开的同一个信号）；短而窄、频率在变的块按候选 0 或跳频集合单独处理。

这个候选能处理相邻和交错的情况，处理不了频率上重叠的情况。

**候选 B（能处理重叠）：时频功率图的非负矩阵分解**
- 对线性功率的 V(f, t)（先减去底噪）做 V ≈ W·H，K 个分量。K 可以从 2–8 里按重构误差的拐点和多次运行的稳定性来选，也可以先用候选 A 的段数作为初值。W 加稀疏和平滑约束，使每个分量在频率上是连续的。
- 每个分量 W_k 中超过最大值某个比例（例如 −10 dB）的频率范围就是一个频带，H_k 就是它的活动序列（可以用来算占空比、给标签）。
- 依据：A15（功率谱分离）、A16（音频 NMF）。风险：跳频分量会被拆成很多分量或者和噪声混在一起；K 的选择；长时间一直开着、没有起伏的源和 Wi-Fi 叠在一起时，分解结果可能不唯一。

**候选 C（给标签 + 处理重叠）：逐频率的循环平稳图**
- 在 IQ 上算谱相关函数在指定循环频率处的值 |S^α(f)|：α_WiFi = 250 kHz（以及 277.8 kHz），α_drone 由实验室纯净的无人机录音扫描得到（对每个机型、每种带宽测一次）。250 MS/s 下 3.2 µs 正好是 800 个样点；FFT 的频率分辨率要比 α 细好几倍（例如 8192 点约 30 kHz），20 ms 能得到约 600 帧来平均。
- 得到两张一维掩码：“这一频率有 Wi-Fi 的 OFDM 结构”和“这一频率有无人机的 OFDM 结构”。频带就从掩码的连续区间得到，标签也同时得到。
- 依据：A12 DOF（多个信号同时存在、0 dB 时 > 85%）、A14。风险：B8 的反例；DSSS 信标没有这个特征；无人机符号长度可能随模式变化；计算量较大。建议先用它做**标签和校验**，而不是作为主切分器。

建议顺序：候选 0 和 A 先做（一两天就能写完，只需要时频图），B 作为重叠情况的补充，C 先在少量片段上验证“Wi-Fi 和无人机的循环频率能不能分开”，再决定用不用。

## 五、评测方案（实验室无人机录音 + 公开 Wi-Fi 录音叠加）

先例：A8（Uvaydov 2024）就是把各协议在空闲频段单独实录的干净信号拼接成宽带样本；WRIST（A7）也专门做了“重叠”的合成子集。我们的做法相同，而且真值可以控制。

1. **在 IQ 上叠加，不在时频图上叠加**：Wi-Fi 录音重采样到 122.88 MS/s（实验室）或 250 MS/s（城区设置），频移到 1/6/11（以及 13）信道的中心，按信干比缩放后和无人机 IQ 相加。注意 Wi-Fi 录音自带的底噪会抬高总底噪，要记录叠加后的实际信噪比，或者只截取 Wi-Fi 录音里有包的部分，再乘一个窗。
2. **真值**：无人机频带用实验室录音在**叠加前**跑现有检测器得到（实验室数据上检测器已经被验证是准的），然后人工抽查；Wi-Fi 频带按放置的信道中心 ± 实际占用宽度（OFDM 约 16.6 MHz、DSSS 约 22 MHz，具体以录音实测为准）。
3. **场景分层**（每层单独报告结果）：
   - 相邻：Wi-Fi 信道和图传之间间隔 0–5 MHz；
   - 交错：图传夹在两个 Wi-Fi 信道之间；
   - 部分重叠：重叠 25% / 50%；
   - 高占空比：叠加 2–4 段独立的 Wi-Fi 录音来模拟多个 AP，让占空比达到 50% / 80% / 约 100%；
   - 信干比：例如 −10 / 0 / +10 dB；
   - 含跳频控制突发的片段和不含的片段分开统计。
4. **对照组**（按“先做对照再下结论”的要求）：只有 Wi-Fi（不应该切出“无人机”频带）；只有无人机（必须复现原来的干净结果）；纯噪声（每段误切的频带数应该约等于 0）；把 Wi-Fi 的时间轴随机打乱后再叠加（检验共同起落方法是不是真的在利用时序独立性）。
5. **指标**（一维频率区间）：
   - 每个真值频带和匹配到的预测频带的频率 IoU，报告 IoU ≥ 0.5 / 0.7 的检出率；
   - 边缘误差（MHz，上下边缘分开报告）；
   - **过切**（一个真值频带被切成几段）和**欠切**（几个真值频带被并成一段）的次数，这正是现在的失败形式；
   - 无人机频带的纯度：预测的无人机频带宽度里有多少其实是 Wi-Fi；
   - 现有检测器（投影 + 间隙合并）作为基线，必须一起报告。
6. **真实城区 2.4G 的检查**：合成集上选出的方法，再拿到城区无人机录音和同期背景录音上画图，人工看切分结果，并统计每段频带数和频带宽度分布（期望不再出现 60–68 MHz 的大频带）。
