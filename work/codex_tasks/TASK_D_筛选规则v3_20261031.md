## 2. 三处修改

### 2.1 排除环境成分
- 在同一频段的全部录制中，若某个合并后子带与 ≥ 80% 录制的某个子带重叠（重叠 ≥ 50% 较窄者宽度），记为**环境子带**，写入 `environment_bands.json`（按频段列出 MHz 区间及出现录制数）。
- 环境子带**不参与**持续特征、主子带、稠密特征、power_shift；但计入 `A_out` 的排除（即不当作"子带外干扰"）。
- 预期 2.4G 至少包含 2426.88–2427.00 MHz。

### 2.2 两级特征：硬丢弃只看"本窗长应当具备"的特征
- **持续特征**（定义同 C：50 ms 窗出现比例 ≥ 0.90）——**只用于报告覆盖率**，不再触发丢弃。
- **稠密特征 dense(L)**（同 C：持续特征中，在当前 L 的窗里出现比例 ≥ 0.90）。
- `lack_feature`（**丢弃条件**）：任一 dense(L) 特征在本窗未出现（`A_k < 0.01`）。
- `coverage`（**仅报告**）：本窗出现的持续特征数 / 持续特征总数。每录制每 L 记 `mean_coverage`，以及 `full_coverage_rate`（coverage = 1 的窗比例）。另列出每录制"非稠密的持续特征"（MHz 区间及其在 10/15/20 ms 下的出现率），这就是"10 ms 截不全"的具体成分。

### 2.3 功率检验只用"信号出现时的强度"
- 新定义 `S_k`（每窗）：子带 k 内，**活跃 cell**（该 cell 在子带内有 ≥ 1 个活跃 bin）的 `cell_max_db` 子带平均值，取这些 cell 的中位数，相对 floor（dB）。窗内活跃 cell < 2 时 `S_k` = NaN。
- `power_shift`：对**主子带**以及 median(A_k@L) ≥ 0.20 的 dense(L) 特征，`|S_k − median(S_k)| > 6 dB`（NaN 不判）。记录哪个子带、偏高还是偏低。
- C 的 P_k 继续写入 CSV，但不再用于判定。

`primary_weak`、`floor_raised`、`interference` 与 C 相同。`discard` = lack_feature OR primary_weak OR power_shift OR floor_raised OR interference。

## 3. 推荐窗长（改）

每录制、每 ref：
- `rec_keep`：保留率 ≥ 0.90 的最短 L；
- `rec_cover`：`full_coverage_rate ≥ 0.90` 的最短 L；
- `recommended` = max(rec_keep, rec_cover)；任一为 none 则 none。
三列都输出。
