## 1. 每次采集要做的事（按目录名、文件名排序，串行，一次只读一个文件）

1. **.bin**：以 8 MiB 块读到底，边读边算 sha256。记录读到的字节数、是否读满 101,000,000、sha256 是否等于 JSON 的 `capture.sha256`，以及报错类型和出错位置。
2. **.mat**：用 h5py 只读打开（anaconda python 有 h5py；`.venv` 没有的话就用 anaconda，记得 `KMP_DUPLICATE_LIB_OK=TRUE`）。分块读完整的 `IQ`（每块 100 万点），记录能否读完、长度是否为 25,250,000、有没有 NaN/Inf，以及 `fs`、`centfreq` 的值。
3. **.bin 与 .mat 是否同一份数据**：
   - .bin 能读出的部分，按 ci16 转成复数，与 .mat 同位置的点比较。
   - **只比较开头 100 万点 + 结尾 100 万点（.bin 读不满时比较其最后可读的 100 万点）**，给出最大绝对差和是否完全相等；若有固定比例差，也给出比例。
   - 不要整段比较，以控制时间。
4. **结论列 `usable_source`**：
   - `bin`：.bin 读满且 sha256 一致；
   - `mat`：.bin 损坏，但 .mat 完整可读、无 NaN/Inf，且在 .bin 可读部分与 .bin 一致；
   - `partial`：两者都不完整，记录能读出的最长连续前缀（毫秒）；
   - `none`：两者都读不出。
5. **防卡死**：单个文件读超过 120 s，就记为超时并跳到下一个文件。可以用子进程加超时实现。不要重试同一坏文件超过 1 次。
