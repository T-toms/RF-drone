# 深度精读与研究重构

本目录是对桌面 `文献` 中 12 个 PDF（10 篇唯一论文）的从零重做。旧 DroneRFa 探索结论不作为前提。

- `00_深度研究总报告.md`：领域主流、权威性判断、项目主线与创新点。
- `01_证据等级_权威性与检索记录.md`：来源、引用、直接性、实验可信度与主张台账。
- `03_研究方向_科学头脑风暴与决策矩阵.md`：独立构思、预设权重、反方审查和决策日志。
- `04_可实现方法_实验协议与里程碑.md`：可直接实施的模型、数据划分、指标与停止规则。
- `05_分类阅读清单与阅读顺序.md`：按研究逻辑而非年份排序。
- `06_无人机RF深度学习项目计划_22周.md`：22 周分阶段执行计划，含文献地址、期刊/会议、验收门槛和停止条件。
- `readers/`：每篇论文的源文锚点式精读、关键图表、复现审计、`source_map.json` 与 `translation_notes.md`。

逐篇读者状态为 **draft deep reader**：覆盖摘要、问题、数据、方法、核心实验、局限和参考文献结构，但没有把全文每个背景段落逐句翻译；这一点在各 `translation_notes.md` 中显式记录。引用原文时应回到源 PDF 的页码锚点核对。
