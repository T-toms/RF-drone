## 3. 细线清点与消除方法

### 3.1 测量（高分辨率）
- 分组：`data/` 2.4G、`data/` 5.8G、`datasets_v3` 每个会话（session id 来自文件名）。
- 每个录制/会话取 ≥ 200 ms 的有效数据（`data/`：每录制取 4 个合格段，均匀分布在两个 epoch；v3：每会话取 2 个文件）。NFFT = 65536、Hann、50% 重叠，平均功率谱。
- 细线判据：比 ±1 MHz 局部中位数高 ≥ 10 dB，且 −10 dB 宽度 ≤ 50 kHz。对每条线再按 10 ms 小块重算，记录"出现率"（≥ 10 dB 的小块比例）、频率在小块间的漂移（kHz）、幅度波动（dB）。
- 合并：同一分组内 ±20 kHz 视为同一条线。输出 `lines_inventory.csv`：group, freq_mhz, offset_from_fc_khz, width_khz, level_db_over_local, presence_rate, drift_khz, amp_std_db, n_recordings_with_line / n_recordings, is_at_fc（|offset| ≤ 300 kHz）。
- 每个分组一张图 `lines_<group>.png`：长时谱（绝对 MHz）+ 标出每条线；另给每条线一个 ±2 MHz 放大子图。

### 3.2 线是否和信号重叠
- 无人机信号频段：`data/` 用缓存 `occ_any ≥ 0.05` 的频点（排除线本身 ±150 kHz）；v3 无人机按同规则先算 1 ms 占用（cell = 1 ms，阈值 floor+10 dB，floor 定义同任务 A）。
- 每条线、每个录制记 `overlaps_signal`（线所在 ±150 kHz 内信号占用率 ≥ 0.05）。背景会话的线一律记 `overlaps_signal=False`（没有无人机信号），但要记它是否落在 §4 规划的截取窗口内。

### 3.3 消除方法（写进 `lab_preproc.py`，两种都实现并验证）
1. **不重叠**：带阻（notch）。线 ±W_notch（W_notch = max(2×width, 60 kHz)）零相位 FIR/IIR 陷波均可，写清参数。截频带的带通若已把线截掉，则无需处理。
2. **重叠**：**正弦对消**。线是窄带、稳定的音，所以按块（默认 10 ms，可调）估计这条线的频率（零填充 FFT 峰值 + 抛物线插值）、复幅度（最小二乘），然后从 IQ 里减掉 `A·exp(j2πf t)`。中心频点上的泄露（is_at_fc 且 offset≈0）另试"块内复均值相减"。
   - 漂移大（drift > 块长对应分辨率的 1/2）或幅度不稳的线，要说明对消效果是否够，必要时把块长调短，在报告里列出最终参数。
- 验证（`cancel_validation.csv` + `cancel_examples.png`）：对每个分组的每条线，在**与信号重叠**和**不重叠**两种录制里各抽 ≥ 3 个 10 ms 片段：
  - 对消后线残留（相对局部底噪，dB），目标 ≤ 3 dB；
  - 离线 ±(150 kHz–2 MHz) 范围内信号频点的功率变化，目标 |Δ| ≤ 0.1 dB；
  - 时域：对消前后误差信号能量 / 片段能量。
  - 达不到目标的线如实列出，不要改阈值凑数。

## 4. 截取中心规划（固定宽度）

- 用户已定：**所有录制统一截固定宽度**。输出采样率 `FS_OUT = 61.44 MS/s`（复数），截取通带 ±28 MHz（即约 56 MHz 宽），过渡带到 ±30.72 MHz。写成常量。
  - `data/`：122.88 → 61.44 用下变频 + `resample_poly(·,1,2)`；v3：100 → 61.44 用 `resample_poly(·,384,625)`。两种实现都写进 `lab_preproc.py`（`crop_band(iq, fs_in, fc_in, f_center_mhz) -> iq_out`），并用合成单音测试：输入在 f_center±20 MHz 的单音，输出频率误差 < 1 kHz、幅度误差 < 0.1 dB；±35 MHz 的单音被抑制 ≥ 60 dB。
- **无人机录制的截取中心**：在可用掩膜内（`data/`：|f_norm| ≤ 0.45；v3：fc ± 45 MHz）滑动 56 MHz 窗，取 `occ_any`（排除 §3 的线 ±150 kHz）之和最大的位置；窗不得越出掩膜。记录 center_mhz、截到的占用能量比例（窗内 occ_any 和 / 全掩膜 occ_any 和）、截取窗是否包含中心频点（fc）。比例 < 0.9 的录制列出。
- **背景的截取中心**：没有信号，不能自己找中心。为了让背景和无人机样本截取的绝对频段一致，背景每个会话的候选中心 = 同频段所有无人机录制（`data/` + v3）的截取中心中，落在该背景会话可用范围内（整窗不越界）的那些；输出候选列表及其覆盖的绝对频段。没有任何候选的会话标 `no_valid_center`。
