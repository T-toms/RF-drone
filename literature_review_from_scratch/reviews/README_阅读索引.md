# 无人机射频信号（RF）文献阅读索引

更新日期：2026-09-03

本目录基于桌面“文献”文件夹中的 12 个 PDF 全文整理。经内容去重后，共有 10 篇唯一论文：`JSAC2026` 文件有一份完全相同的副本；`Combined RF-based drone detection and classification` 有预印本与另一份同文 PDF，均只综述一次。

## 建议阅读顺序

1. [DroneRFa：大规模无人机射频信号数据集](01_DroneRFa_数据集综述.md)：先了解本项目最可能使用的数据结构、频段、距离和基线。
2. [低 SNR、低成本系统与野外验证](03_低SNR低成本检测分类_综述.md)：了解“能否落地”和真实环境中性能下降的位置。
3. [两阶段与 YOLO 联合检测分类](04_TCCN2022_联合检测分类_综述.md)：建立检测、频谱定位、分类及多信号处理的完整流程观。
4. [TVT 2021：前导码特征与联邦学习](06_TVT2021_前导码与联邦学习_综述.md)：学习物理先验与跨信道鲁棒特征。
5. [TVT 2020：非标准波形的个体射频指纹](05_TVT2020_非标准波形RFF_综述.md)：区分“机型识别”与“同型号个体识别”。
6. [Open-RFNet：开放集识别](02_JSAC2026_OpenRFNet_综述.md)：了解未知机型拒识及其局限。
7. [DRFF-R2：多场景、多机、多日、多接收机数据](07_DRFF-R2_多场景数据集_综述.md)：用于设计更严格的跨域实验。
8. [RFF-LLM 与动态知识蒸馏](08_RFF_LLM_动态蒸馏_综述.md)：作为轻量化与复杂教师模型的进阶路线。
9. [SDR-Lite：普通 Wi-Fi 网卡重建物理层信号](09_MobiCom2020_SDR-Lite_综述.md)：作为低成本接收系统的系统创新参考。
10. [ResNet 原始论文](10_ResNet_CVPR2016_方法基础_综述.md)：只作为骨干网络与残差学习背景，不作为无人机 RF 领域证据。

## 证据使用原则

- 本轮结论仅来自上述 PDF，不采用此前 DroneRFa/RFUAV 试探性实验结果。
- “准确率高”不直接等于“可部署”；优先检查设备、采集会话、日期、接收机和环境是否真正隔离。
- 会议/期刊层级、论文与项目的直接相关性、实验严谨性分别评价，不把三者混为一谈。
