## 3. 每录制的"应有特征"（参照分布）

在 `cell_max_db` / `cell_mean_db` 上，阈值 floor+10 dB（floor 取 meta.json），只用掩膜内 bin：

- 对 `occupied_bands.json` 里的每个子带 k（映射回折叠 bin 区间），每个 cell 计算：
  - `act_k[t]` = 该子带内 `cell_max_db > floor+10` 的 bin 比例；
  - `pow_k[t]` = 该子带内 `cell_mean_db` 的线性平均再转 dB（相对 floor）。
- 子带外（掩膜内、不属于任何子带的 bin）：`act_out[t]`。
- 窗特征 = 窗内各 cell 的平均：`A_k`、`P_k`（dB 的平均按线性平均再转 dB）、`A_out`。
- **特征子带**：该录制在窗长 L 下，`A_k` 的窗中位数 ≥ 0.02 的子带。
- **主子带**：特征子带中 `median(A_k) × 子带宽度(bin)` 最大的那个。
- 若某录制没有特征子带：该录制所有窗标 `no_characteristic`，不参与筛选，单独列出。

## 4. 每窗标记

参照范围有两种，**两种都算，都输出**：
- `ref=recording`：整次录制的所有窗；
- `ref=epoch`：只用 epoch_start 相同的窗（跨 epoch 的窗归入 epoch_start）。

对每种参照，每窗：

1. **missing_primary**：`A_primary < 0.25 × median(A_primary)`。
2. **missing_all**：所有特征子带都满足 `A_k < 0.25 × median(A_k)`。
3. **differ**：对每个特征子带的 `log1p(A_k)`、`P_k`，以及 `log1p(A_out)`，计算鲁棒 z = (x − median)/max(1.4826·MAD, floor)，floor 分别为 0.05、1.0 dB、0.05；任一 |z| > 3.5 → differ。记下是哪一项触发（`differ_reason`，如 `sb2_pow_low`、`out_act_high`）。
4. **discard** = missing_primary OR differ（这是**候选规则**，最终采用与否由用户决定）。

## 5. 窗长选择（"或者截取更长的片段"）

- 每录制、每 L、每种 ref：n_windows、n_missing_primary、n_missing_all、n_differ、n_discard、保留率 = 1 − n_discard/n_windows。
- **推荐窗长**（每录制、每种 ref）：保留率 ≥ 0.90 的最短 L；都不满足则写 `none`。
- **主子带间隙统计**（与 L 无关，用 1 ms 序列）：主子带 `act_primary[t] > 0` 为"有"，统计有效区间内连续"无"的长度（ms）的 p50、p95、max。p95 ≥ L 说明该窗长容易截到"空窗"，写进汇总供参考。
