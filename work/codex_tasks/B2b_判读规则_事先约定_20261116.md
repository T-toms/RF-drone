# 任务 B2b 判读规则（2026-11-16 事先约定，在看到任何结果之前写定）

给协调者自己和汇报用，不发给 worker 当停止条件。结果出来后照此判读，不事后改规则；如果确实要改，另写一节说明原因。

## 1. 比什么

- **特征的作用 = F − Z、F5 − Z**（同一种子、同一份缓存，配对相减）。Z − R 只反映网络结构的变化（多了 LayerNorm、Dropout、拼接头），不算特征的作用。
- 主要看**接收机 B** 的指标：v3 test 虚警、v3 无人机召回；2.4G 另看 C1 虚警、陷波白噪声虚警。接收机 A（bgA、data）已饱和（J/L-a/L-b 的 bgA test 都是 0/1287），只作检查，不作判断依据。
- 非 G 漏检、mavic2、mini3pro 作辅助参考。

## 2. 判据（argmax 为主，thr_fa1 作复核）

依据：L-b 的 3 个种子标准差为 v3 无人机召回 ±9.5 个百分点、非 G 漏检 ±4.1 个百分点；v3 test 背景 80 片，1 片 = 1.25 个百分点。

| 结论 | 条件 |
|---|---|
| 有改善 | 3 个种子 F−Z 方向一致，且均值达到：v3 无人机召回 ≥ +5 个百分点，或非 G 漏检 ≤ −2 个百分点；同时虚警没有变差（见下） |
| 虚警没有变差 | v3 test 虚警均值上升 ≤ 1.25 个百分点；C1 虚警均值上升 ≤ 1 个百分点 |
| 变差 | 3 个种子方向一致，且召回下降 ≥ 5 个百分点，或任一虚警超过上面的容许值 |
| 无明显差别 | 都不满足，或 3 个种子方向不一致 |

“无明显差别”也是有效结果，照实汇报。

## 3. 是否走了捷径

- F 中，spec_flatness、shape_factor、c42n、log_gamma_max、log_kurt_a 任一列单独打乱后，v3 无人机召回或 v3 test 虚警的均值变化 ≥ 5 个百分点 → 记为“F 依赖了 B1b 标为接收机指纹或可疑的特征”。
- 特征依赖度 (a) 全打乱、(c) 全置 0 后，F 的指标几乎不变（< 2 个百分点）→ 记为“网络基本没用特征”。这时 F−Z 的差异主要来自训练的随机性。
- 5.8G 的接收机 A 只有无人机片，接收机与标签混在一起；如果 5.8G 的 F 改善只出现在 data（接收机 A）召回上，不算改善。
