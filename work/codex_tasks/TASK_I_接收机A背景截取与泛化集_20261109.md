## 3. 试点：选 s，并做有效性检验

先取 8 个 data/ 2.4G 块做试点：`power_db_median` 最高的 4 个 + `bg_feasibility` 统计里 2393.5–2398.6 MHz 占用率最高的 3 个 + 012（不重复则补足）。对每个块生成 s = 0 和 s = 2 两个背景块（与对应无人机块**同长度、同采样点对齐**），然后做：

**(a) 镜像/泄漏检验（最重要，可推翻本方法）。** 接收机的 IQ 不平衡会把 fc+Δ 处的无人机信号以 −IRR dB 映到 fc−Δ；共轭后它会落在背景样本中**与无人机信号相同的时频位置**。另外 2393–2398 MHz 的裙边也会与无人机发射同步出现。检验方法：对同一块的无人机 IQ 和背景 IQ 用与模型相同的 STFT（n_fft 1024，hop 512，Hann，只取 2405–2455 MHz 的 bin），算每个 (t, f) 相对各自每个 bin 中位数的超出量 D(t,f)（无人机）与 B(t,f)（背景）。报告：B 在 {D > 20 dB} 的格子上的平均功率（先线性平均再转 dB）减去 B 在 {D < 3 dB} 格子上的平均功率 = Δ_img；同样算 {D > 30 dB}。再按 1 MHz 子带分别算 Δ_img，找出哪些频率有泄漏。
**判据（事先定好）：** 每个块整个频段 Δ_img(D>20) ≤ 0.3 dB，且每个 1 MHz 子带 ≤ 1 dB，算通过。

**(b) 底噪形状检验。** 对每个块：无人机 IQ 中"安静"的 1 ms 单元（截取频段内所有非陷波 bin 都 < 该块底噪 + 3 dB）的平均功率谱，与背景 IQ 的平均功率谱，按 1 MHz 分辨率相减（跳过陷波点 ±0.3 MHz）。安静单元 < 50 个的块跳过并注明。**判据：** 差值绝对值 ≤ 0.5 dB。同时叠画 v3 背景（07-10 lab 与 07-09 urban 各一个块）的平均谱作参考。

**选择规则：** s = 0 两项都通过 → 用 s = 0；否则 s = 2 两项都通过 → 用 s = 2；两个都不通过 → 把两组数字发 `ask`，等协调者决定，不要自己放宽判据。
