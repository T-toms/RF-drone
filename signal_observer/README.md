# 本地MAT信号观察脚本

双击项目根目录的 **打开本地信号观察.cmd**。使用本机已有的 `D:\anaconda\pythonw.exe`，不启动网页服务，不需要安装或打包。

## 使用

1. 点“选择文件”，选择MAT；通常变量选 `data`，raw转换MAT选 `IQ`。
2. 观察范围选“仅当前MAT”或“整次录制”。两者均从清晰局部开始，默认视窗262,144点，整文件/整次录制作为可浏览范围。后者仅适用于已审计的 `G:\drone\data`，按同一录制的epoch/seg排序，包含原train/test存放目录中的段，确认副本不重复接入，缺段原位留空。
3. Fs未知时留空，坐标显示样点和归一化频率。可点“填候选122.88”明确采用推定采样率，坐标才换算为时间和相对MHz。接收中心可留空；只有填写Fs和真实中心时才换算绝对射频频率。**2.4G/5.8G目录名不自动作为精确接收中心。**
4. 点“生成 / 更新图”。四行依次是整段位置参考、当前视窗平均功率谱、清晰局部时频图、功率包络。通过“细节显示”切换平均谱/峰值谱。
5. **用四个明显的移动按钮操作：开头、向前移动、向后移动、末尾。**向前/向后每次移动半个视窗；也可拖动“时间位置”滑块到整段任意位置。拖动时只更新待定位提示，松开后计算并更新主图。主图本身不接收拖动；缩放使用“放大×2 / 缩小×2”按钮，或直接填写“局部视窗样点数”后点“应用宽度”。“20ms视窗”需要Fs；未知Fs时按样点操作。
6. “全部”清空起点/长度限制，随后点“生成 / 更新图”。20 ms、100 ms、1秒按钮只填写样点数，需先有Fs；如果文件长度不足，会显示实际范围并明确提示截到末尾，**不会补零生成更长信号**。要观察超过一个MAT的长度，先切换“整次录制”。
7. 点“保存PNG与参数”，结果保存在 `output\signal_observer`：PNG、JSON参数与来源区间、NPZ数值统计。原始IQ始终只读。统计缓存不包含原始IQ。

## 连续播放

图生成后点击 **▶ 播放**，局部视窗从当前位置自动向后移动，直到整段末尾。播放中按钮变成 **Ⅱ 暂停**，可随时停下检查；再次播放从停下的位置继续。在末尾再次播放会从头开始。**■ 停止并回开头**会停止播放并定位到开头。

- 浏览速度可选2、5、10步/秒，每步前进1/4、1/2或1个视窗，默认5步/秒、半个视窗。步长不大于视窗，连续覆盖，不跳过中间时间区间。
- 这是供观察的自动浏览速度，**不是采样时间的实时倍速**，不需要确认Fs。计算慢于设定速度时会等待下一视窗，实际速度可能降低。保持清晰局部尺度时，完整浏览长录制会比其采集时长慢很多；要加快观察可扩大局部视窗或选择每步1个视窗。
- 提前在后台计算下一视窗，并复用已有IQ/统计缓存；不会为追赶速度跳帧。缺段仍按原位置显示空白，然后继续播放。
- 使用移动按钮、拖动时间滑块、缩放或重新选择文件时会暂停，避免自动播放与手动定位争抢位置。暂停会阻止正在准备的播放画面随后覆盖当前图。

也可以直接运行：

```powershell
& 'D:\anaconda\python.exe' 'C:\Users\Administrator\Desktop\数据集处理\signal_observer\local_observer.py'
```

## 之前展示的图片到底多长

时间公式为 `T = 样点数 / 采样率`。下表**仅按122.88 MS/s候选值换算**，不是对整批采集参数的最终确认：

|范围|复数样点数|对应时间|
|---|---:|---:|
|之前的局部放大图|262,144|约2.13 ms|
|一个data MAT|6,144,000|50 ms|
|连续40段的坐标跨度|245,760,000|2秒|

因此局部图确实很短。现在默认保留这种清晰局部尺度，通过按钮和滑块浏览整个文件或更长录制；可以自行缩小至更长时间视窗。存在缺段时，坐标跨度包含缺失时间，但缺失区间不进入功率统计。

## 处理与解释范围

- 支持MAT v5/v7的一维复数向量，以及MAT v7.3/HDF5复数或real/imag复合类型向量。不自动把实数矩阵解释成IQ。
- STFT采用Hann窗。整段参考统计采用非重叠FFT帧；局部视窗默认2048点FFT、512点步长，保留75%重叠。显示最多约2000个时间格、1024个频率格，长范围按格聚合。原始IQ没有抽点或重采样；重叠帧重复使用的点不会重复算作“覆盖IQ点数”。
- 很短的突发在长范围中可能只占一个显示格，应使用缩放按钮缩小视窗后重新计算；不能用概览图的像素边界当精确帧边界。
- 灰色表示没有完整统计帧，包括缺段、被排除区间和FFT边缘；深色只表示相对能量低。亮区不自动赋予图传、遥控、干扰或机型真值。
- 文件内有fs/centfreq等参数时会读取，并标记“来自文件”；手填值标为“用户输入/推定”。“只更新坐标”不需要重算FFT。
- 未选择训练划分，也不执行筛窗删除或训练。

## 验证

`test_analysis.py`现有18项检查，包括缺段、无效前缀、范围截断、重叠帧、MAT v5/HDF5、时钟来源、缓存失效/容量限制及图像坐标更新。`test_playback.py`用确定性计时器检查实际播放事件流程的10种情形：完整覆盖/末尾停止、暂停丢弃未显示画面、缓冲、手动跳转、停止回头、重播、缺段、读取错误及速度/步长修改。它不控制原生窗口；界面人工操作与逻辑测试分别记录。`demo_and_verify.py`在真实data上读取一个完整MAT和40段录制，并与此前长录制平均功率谱交叉核对。

## 移动性能

程序在内存中保留最多128 MiB的v5 MAT只读IQ缓存，以及最近8个局部统计结果；更换文件后清空，退出后释放。文件大小或修改时间发生变化会使相应缓存失效。HDF5仍采用只读分段读取，不在缓存中保留打开的文件句柄。不会复制原始IQ到硬盘。

移动时复用坐标轴、色条和图像对象，不再重建整个图。真实009录制的262,144点视窗测试中，同一文件内已预热的“分析+绘制”耗时中位数由约555 ms降至191 ms；这是本机Agg绘图基准，不是保证的界面帧率。首次读取新MAT仍有加载时间。基准脚本为`benchmark_navigation.py`，原始计时在`output/signal_observer/*_navigation_timings.json`。滑块拖动过程不触发FFT或绘图。
