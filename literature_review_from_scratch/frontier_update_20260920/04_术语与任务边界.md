# 术语与任务边界

**版本：2026-09-20** ｜ 本文件定义 `01_文献矩阵.csv` 的字段词表，并说明为什么不同论文的准确率不能横比。

---

## 1. 七个任务层级（`task_level` 词表）

`task_level` 只允许取以下七个值之一。取值依据是**输入单位与输出单位**，不是论文标题里的措辞。

| 值 | 中文 | 输入 | 输出单位 | 典型主指标 | 属于本层的代表条目 |
|---|---|---|---|---|---|
| `activity_detection` | 活动检测 | 任意时间窗/频带 | 有/无 | 检测概率、虚警率、FPR/hour | `M001`、`M006`、`M025`（GoF 分支） |
| `tf_localization` | 时频定位 | 连续宽带流或时频图 | 时频框 | mAP@IoU、定位误差 | `M025`、`M039` |
| `model_classification` | 型号/协议族分类 | **已被裁剪**为单信号的窗 | 类别标签 | balanced accuracy、宏 F1 | `M002`、`M034`、`X006` |
| `individual_rffi` | 个体射频指纹 | 突发/片段 | 物理设备标签 | 跨突发准确率、未知个体拒识 | `M007`、`M042`、`A001` |
| `open_set` | 开放集识别 | 窗 | 已知类标签或"未知" | KAR/UAR、AUROC、OSCR、FPR@95TPR | `M035`、`X003`、`M032` |
| `incremental_open_world` | 开放世界增量 | 窗流 | 已知类 + 新发现类 | 开放集指标 + 聚类有效性 + 遗忘率 | `X005` |
| `multi_emitter` | 多发射源 | 含多个同时发射源的流 | 实例（源） | 实例级 mAP + 逐实例分类 F1 | `M018`、`M039` |

### 1.1 三个最容易混淆的边界

1. **存在检测 ≠ 已裁剪窗口分类。** 前者输入含背景与未知信号，输出二值；后者输入已被切成只含单个目标信号的窗，输出类别。用后者的 accuracy 声称前者能力是越界。
2. **型号分类 ≠ 个体 RFFI。** 型号之间的差异是结构性的（带宽、跳频图案、占空比、图传周期）；个体之间的差异只有硬件制造公差。前者容易学到，也容易与非目标变量（中心频率、增益、采集批次）绑定；后者主要受信道、接收机频响与漂移支配，跨突发极易崩溃（`M007`：随机相邻切片约 97% → 跨突发约 49–50%）。
3. **时频定位 ≠ 多发射源识别。** 定位可以只回答"信号在哪"，不需要给出实例身份；多发射源任务要求把定位结果与身份一一对应，难度更高。

## 2. 证据类型（`evidence_type` 词表）

| 值 | 含义 | 允许用它支持什么 | 不允许用它支持什么 |
|---|---|---|---|
| `direct_uav_rf` | 面向被动 UAV/遥控器通信 RF 的同一任务 | 方法、数据、评测主张 | 未经核对就外推到其他频段/接收机 |
| `adjacent_rffi` | 一般无线 RFFI 或通用方法（含通用视觉骨干、通用接收系统） | 方法迁移线索、术语与机制解释 | 直接作为 UAV 型号识别或 UAV 个体识别的结论 |
| `dataset` | 数据/基准资源（含数据论文与数据仓库条目） | 数据可得性、划分可行性 | 作为方法性能证据 |
| `review` | 综述 | 发现文献、建立术语、了解领域演进 | 作为数值或 SOTA 证据（必须回到原文） |

`X007`（无类别盲活动检测设计）是项目内部方法论条目，不是外部论文证据；其 `venue_or_status` 与 `doi_or_url` 已在该行显式标注不表示发表状态。

## 3. 矩阵字段说明

| 字段 | 含义 | 填写规则 |
|---|---|---|
| `id` | 条目编号 | `M###` = 既有 63 条候选元数据中保留的条目；`X###` = 本轮新增前沿来源；`A###` = 相邻 RFFI/通用方法 |
| `year` | 年份 | 取自 Crossref/DataCite 或原始页面；在线优先出版年份按元数据记录 |
| `title` | 标题 | 原始标题，不翻译（中文文献保留中文原标题） |
| `venue_or_status` | 发表平台或状态 | 必须区分"正式期刊/会议"与"预印本/数据手稿" |
| `doi_or_url` | 直链 | 优先 DOI；无 DOI 用 arXiv 或官方页面；本列在 77 行中无空值 |
| `evidence_type` | 见第 2 节 | 四值之一 |
| `task_level` | 见第 1 节 | 七值之一 |
| `dataset` | 数据来源 | 既有条目沿用本地元数据的 `track` 分类；新增条目未核实时写 `NR` |
| `class_scope` | 类别范围 | 写类别数、设备数与标签语义（型号/个体/状态） |
| `input_representation` | 输入表征 | 如"原始复数 I/Q""STFT 时频图""PSD 特征" |
| `sample_unit_or_length` | 样本单位或长度 | **不清楚写 `NR`**。不得猜测窗口长度、采样率或点数 |
| `split_unit` | 切分单位 | **不清楚写 `NR`**。不得猜测是随机窗口、按文件还是跨会话 |
| `domain_conditions` | 域条件 | 距离、环境、接收机、干扰、SNR 等；未核到写 `NR` |
| `main_metrics` | 主指标 | 只写论文报告的量与口径；不换算、不排名 |
| `code_or_data` | 代码/数据可得性 | 有官方仓库/DOI 就写直链；无写 `NR` |
| `evidence_status` | 发表与核验状态 | 与 `verification_level` 配合，标明是否正式发表 |
| `main_limit` | 主要局限 | 必须写，不允许留空 |
| `project_relevance` | 对本项目的作用 | 说明它支撑或否证本项目的哪一条判断 |
| `verification_level` | 本轮核验层级 | 全文精读 / 原始页面级 / 元数据级，三者之一（可附说明） |

### 3.1 关于 `NR`

`NR` = not reported / not verified **in this round**。它表示"本轮没有核到"，**不表示论文没有报告该信息**。矩阵中 `sample_unit_or_length` 有 68 行、`split_unit` 有 66 行、`code_or_data` 有 58 行为 `NR`，原因是绝大多数条目本轮只核到 Crossref/OpenAlex 元数据。需要这些字段时应先获取全文，补填后同步升级 `verification_level`。

## 4. 为什么不同论文的准确率不能横比

以下六条必须同时满足，两个数字才可比：相同的任务层级、相同的类别数、相同的切分单位、相同的样本独立单位、相同的域条件、相同的类别定义。实际文献中几乎不可能同时满足。

具体反例：

| 对比 | 表面差异 | 实际差异 |
|---|---|---|
| DroneRFa 论文 97.73% vs 本项目 `CASCADE3` clean 99.75% | 后者"更高" | 前者是 25 类随机窗口切分；后者是 3 类文件留出且 heldout 已参与过选型。类别数与切分都不同 |
| 本项目 3 分类 99.75% vs Open-RFNet UAR 96.08% | 后者"更低" | 前者是闭集 3 类 accuracy；后者是 25 类型设置下 20 已知/5 未知的开放集 UAR。指标定义不同 |
| DroneRF 论文 97.x% vs TVT 2020 跨突发约 49% | 差距巨大 | 任务不同（型号 vs 同型号个体），且样本单位不同（随机切片 vs 跨突发） |
| Sensors 2024 同环境 ≈99% vs 换环境 81/53 | 同一论文内 | 说明即使同任务同模型，域条件一变结论就变；跨论文比较更不可靠 |

**因此本矩阵不做排行榜，也不在任何文件中给出跨论文的性能排序。**

## 5. 划分协议命名（与路线图一致）

| 名称 | 含义 | 允许的表述 |
|---|---|---|
| `P0_random_window` | 按窗口随机划分 | 只作复现对照，必须显式标注，不得进入主结论 |
| `P1_group_file` | 同一原始文件的全部窗口只属于一个集合 | 可称"文件级分组/文件级留出"，**不得**称"跨会话" |
| `P2_cross_session_day` | 完整会话/日期留出 | 仅在元数据可证明会话或日期时使用 |
| `P3_cross_receiver_or_distance` | 接收机或距离域留一 | 仅在元数据可证明时使用 |
| `P4_cross_dataset` | 训练与测试来自不同数据集 | 先对齐共同层级标签，再谈型号级 |

## 6. 指标口径纪律

- **主口径**：文件等权（先算每个源文件的正确率，类内源文件等权，再按类等权）。本项目所有已验收实验的主口径都是它。
- **辅助口径**：pooled 窗口口径。两者必须同时给出且不得混用。
- **开放集**：必须同时报告已知类准确率与未知拒识指标（KAR/UAR、AUROC、OSCR、FPR@95TPR），并说明阈值来自哪个校准集。
- **校准**：报告 ECE 或 Brier；校准集必须含代理未知，且与最终测试未知类隔离。
- **检测**：报告 FPR/hour 而不只是准确率；窗口长度引入的延迟必须计入端到端延迟。
- **重复单位**：独立会话或未知类划分，不是相邻窗口。报告均值、样本标准差与置信区间，并写明重复次数。
