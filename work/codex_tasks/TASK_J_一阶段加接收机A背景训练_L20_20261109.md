## 1. 唯一的改动（以及为加入它必须定的两条规则）

| 项 | 任务 H | 本任务 |
|---|---|---|
| 2.4G train 背景 | v3 背景 234 片 | v3 背景 234 片 + **bgA train 且 keep==True 的 2861 片** |
| 2.4G val 背景 | v3 背景 80 片 | v3 背景 80 片 + bgA val 且 keep==True 的 990 片 |
| 损失权重 | 类别频率倒数（两类总权重相等） | **两类总权重仍相等；背景类内部 v3 与 bgA 各占一半**（见下） |
| 选模型 | val 上 FA + Miss 最小，并列取 val loss 低者 | val 上 **FA_v3 + FA_bgA + Miss** 最小，并列取 val loss 低者 |
| thr_fa1 | val 背景 FA ≤ 1% 的阈值 | 分别对 v3 val 背景和 bgA val 背景按任务 H 同一公式求阈值，**取两者中较大的** |

权重规则（逐样本，写进 REPORT）：设 train 中无人机 N_d、v3 背景 N_v、bgA N_a。样本权重 w = 1/N_d（无人机）、0.5/N_v（v3 背景）、0.5/N_a（bgA），再整体缩放使 train 集上 w 的均值 = 1。每个 batch 的损失 = Σ(w_i·CE_i) / Σ(w_i)（与任务 H `F.cross_entropy(weight=类别权重)` 的归一方式一致）。val loss 用同一套权重规则（以 train 的 N_d、N_v、N_a 计算）。
理由：若只按类别加权，v3 背景（唯一带 WiFi 的背景）在背景类中的权重会从 100% 掉到 7.6%，等于同时改了第二件事。

**其他全部与任务 H 相同**：输入（直接用已有缓存，不重算）、`ResNet18(1,2)`（`dronerfa_baseline/model.py`，不改）、AdamW lr 1e-3、weight_decay 1e-4、cosine 到 1e-5（T_max 40）、40 epoch、batch 64、AMP 自动选、种子 2026/2027/2028、`seed()` 写法、`torch.backends.cudnn.benchmark=True`、不做增强、不加噪、不调参。**训练脚本以 `work/train_stage1_L20_20261108/train.py` 为底本复制修改**，在 REPORT 中列出与它的 diff（应只涉及数据拼接、权重、选模型、阈值、路径）。
